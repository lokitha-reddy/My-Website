# 🌐 Narapureddy Lokitha -- Portfolio Website

A responsive personal portfolio website built with **HTML, CSS, and
JavaScript**.\
It showcases my **skills, projects, experience, certifications, and
achievements** in a modern, interactive design.

------------------------------------------------------------------------

## 📂 Project Structure

    .
    ├── index.html      # Main HTML file
    ├── styles.css      # CSS styles
    ├── script.js       # JavaScript functionality

------------------------------------------------------------------------

## ✨ Features

-   📱 **Responsive Design** -- Optimized for desktop, tablet, and
    mobile devices\
-   🎨 **Modern UI/UX** -- Gradient backgrounds, animations, and hover
    effects\
-   📌 **Navigation System** -- Sticky header, smooth scrolling, scroll
    spy, and mobile menu toggle\
-   👤 **Hero Section** -- Profile badge, social links, and contact
    info\
-   📊 **Skills & Expertise** -- Categorized with tags (Programming,
    Analytics, UI/UX, Soft Skills)\
-   💼 **Projects Section** -- Showcases featured projects with live
    demo and GitHub links\
-   🕑 **Experience Timeline** -- Interactive professional experience
    with achievements\
-   🏆 **Achievements & Stats** -- Hackathons, leadership roles, and key
    highlights\
-   🎓 **Certifications** -- Cards with provider info, skills gained,
    and verified badges\
-   📬 **Contact Section** -- Contact info, social links, and a working
    form\
-   📥 **Download Resume** -- Exports resume text file with one click\
-   🔔 **Notifications System** -- Success/error messages for resume
    download & form submission\
-   ✨ **Animations** -- Elements fade in on scroll using Intersection
    Observer

------------------------------------------------------------------------

## 🚀 Getting Started

### 1. Clone Repository

``` bash
git clone https://github.com/lokitha-reddy/My-Portfolio.git
cd My-Portfolio
```

### 2. Open in Browser

Simply open `index.html` in your browser.\
*No server setup required.*

## 🛠️ Technologies Used

-   **HTML5** -- Semantic structure\
-   **CSS3** -- Flexbox, Grid, gradients, animations, responsive design\
-   **JavaScript (ES6)** -- Navigation, scroll spy, form validation,
    resume download\
-   **Lucide Icons** -- Modern SVG icons\
-   **Pexels Images** -- Stock images for projects
